# Focus Board
A lightweight task prioritization app that helps users organize tasks into Now, Soon, and Later using a simple drag-and-drop interface. Built as part of a vibe coding assessment focused on learning how to analyze, question, and improve AI-generated code.

## Tech Stack
React (Vite)
TypeScript
Tailwind CSS
Native HTML5 Drag and Drop API

## Features
Add tasks with a title
Automatically assigns timestamp on creation
Drag and drop tasks between columns:
Now
Soon
Later
Delete tasks
Clean, minimal UI for focused task management
